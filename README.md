
# 🎮 **Nomino**

*A fast, category-based word game built with Flutter.*

Welcome to the public showcase repo for **Nomino**.
This repository contains **releases, screenshots, demos, and documentation** for the project.
The full source code is kept private — this repo focuses on what the app does and how it works from a user perspective.


## ✨ What is Nomino?

Nomino is a fun, fast-paced word challenge game where players must think quickly and name items that fit different categories — all starting with one letter.

Perfect for:

* solo challenges
* casual play
* competing with friends
* sharpening vocabulary and recall speed


## 🎯 Core Features

* 🅰️ **Letter-based rounds** — get one letter and race to answer categories.
* 🗂️ **Rich categories** — animals, countries, food, colours, emotions, and more.
* 🎨 **Beautiful UI** — custom visuals, animations, and themed game screens.
* ⏱️ **Multiple game modes** — solo, timed rounds, and challenge variations.
* 💡 **Hint system** — get help when you’re stuck (with coin deductions).
* 🎵 **Smooth experience** — no ads, minimal loading, clean interactions.

(More features can be added as the app grows.)
